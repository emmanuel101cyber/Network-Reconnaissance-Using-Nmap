 Project 1: Network Reconnaissance Using Nmap

 Overview

This beginner cybersecurity project demonstrates basic network reconnaissance using Nmap.

 Objective

To learn how to identify open ports and understand the network services running on an authorized target.

Tools Used

* Kali Linux
* Nmap

Methodology

1. Checked the Nmap installation.
2. Selected an authorized testing target.
3. Performed a basic network scan.
4. Analyzed the scan results.
5. Documented the findings.
